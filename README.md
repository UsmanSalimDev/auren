# AUREN

A responsive fragrance storefront built with React and Vite, styled around an
ivory, navy, and warm-gold palette.

## Run locally

```sh
npm install
npm run dev
```

## Pages

- `/` — home and signature collection
- `/shop` — fragrance catalogue
- `/shop/:productId` — fragrance details
- `/collections` — curated collection
- `/story` — brand story

The navigation, mobile menu, fragrance filters, shopping bag, and newsletter
form are client-side interactions. GSAP powers the hero and scroll reveals;
Framer Motion handles page, card, toast, and shopping-bag transitions.
